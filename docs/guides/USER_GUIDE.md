# 📖 User Guide - Agricultural Intelligence System

## 🇬🇧 English Version

### Getting Started

Welcome to the Agricultural Intelligence System! This guide will help you use all features of the application.

### 1. Setting Up Your Profile

1. **Open Settings** - Click the ⚙️ gear icon in the sidebar
2. **Select Language** - Choose your preferred language (English, Hindi, Telugu, Tamil, or Kannada)
3. **Enter Location** - Select your state for accurate weather data
4. **Enable GPS** (Optional) - Click "Get Location" for precise weather based on your farm location
5. **Save Settings** - Click the "Save" button

### 2. Understanding the Dashboard

The main dashboard shows:
- 🌡️ **Current Weather** - Temperature, humidity, and conditions
- 📊 **Quick Stats** - Summary of your last analysis
- 🔔 **Alerts** - Weather warnings and recommendations

### 3. Using the Soil Fertility Module

**What you need**: NPK values from your Soil Health Card

1. Navigate to **Soil Fertility** in the sidebar
2. Enter values:
   - **Nitrogen (N)**: 0-200 mg/kg
   - **Phosphorus (P)**: 0-200 mg/kg
   - **Potassium (K)**: 0-300 mg/kg
3. Click **"Check Fertility"**
4. View results:
   - 🟢 **Fertile** - Ready for planting
   - 🟡 **Semi-Fertile** - Needs improvement
   - 🔴 **Infertile** - Urgent treatment needed

### 4. Using Weather Intelligence

1. Navigate to **Weather Intelligence**
2. Select the **Month** using the slider
3. Enter current **Temperature**
4. Click **"Analyze Risk"**
5. Results show:
   - 🌊 **Flood Risk** - Prepare for heavy rainfall
   - 🔥 **Drought Risk** - Increase irrigation
   - ✅ **Normal** - Good conditions

### 5. Getting Crop Recommendations

1. Navigate to **Crop Recommendation**
2. Fill in all required fields:
   - Soil nutrients (N, P, K)
   - pH level (0-14, ideal: 6.0-7.0)
   - Temperature and Humidity
   - Rainfall amount
3. Click **"Recommend Crop"**
4. View the recommended crop with growing tips

### 6. Predicting Yield

1. Navigate to **Yield Prediction**
2. Enter:
   - Crop name (Rice, Wheat, Maize, etc.)
   - Season (Kharif, Rabi, Whole Year)
   - State name
   - Farm area in hectares
   - Annual rainfall
   - Fertilizer used
3. Click **"Predict Yield"**
4. See expected production in tons and estimated market value

### 7. Getting Fertilizer Advice

1. Navigate to **Fertilizer Advisory**
2. Enter soil and crop details
3. Click **"Get Recommendation"**
4. View:
   - Recommended fertilizer type
   - Application method
   - Dosage and timing

### 8. Using the AI Chatbot

The chatbot can answer your farming questions in your language!

**To open**: Click the 💬 chat icon (bottom-right corner)

**Features**:
- **Voice Input**: Click 🎤 microphone to speak
- **Quick Questions**: Click suggested questions
- **Voice Output**: Enable/disable with 🔊 speaker icon

**Example questions**:
- "What crop should I grow?"
- "How is my soil health?"
- "Tell me about weather risk"
- "What fertilizer should I use?"

### 9. Complete Farm Analysis

For a comprehensive report:
1. Navigate to **Unified Report** (⚡ icon)
2. Fill in all farm data
3. Click **"Analyze My Farm"**
4. Receive complete analysis including:
   - Soil health score
   - Weather risk assessment
   - Recommended crop
   - Expected yield
   - Fertilizer plan

### 10. Edge Cases & Troubleshooting

**Invalid pH Value (>10 or <3)**:
- The system will warn you that extreme pH values are unusual
- Normal soil pH ranges from 4.5 to 8.5

**No Internet Connection**:
- The app works offline with cached data
- Weather data may not be current
- All prediction modules still function

**Voice Not Working**:
- Check browser permissions for microphone
- Use Chrome or Edge for best voice support
- Type your message if voice fails

## 🇮🇳 हिंदी संस्करण (Hindi Version)

### शुरुआत करना

कृषि बुद्धिमत्ता प्रणाली में आपका स्वागत है! यह गाइड आपको एप्लिकेशन की सभी सुविधाओं का उपयोग करने में मदद करेगी।

### 1. अपनी प्रोफ़ाइल सेट करना

1. **सेटिंग्स खोलें** - साइडबार में ⚙️ गियर आइकन पर क्लिक करें
2. **भाषा चुनें** - अपनी पसंदीदा भाषा चुनें
3. **स्थान दर्ज करें** - सटीक मौसम डेटा के लिए अपना राज्य चुनें
4. **GPS सक्षम करें** (वैकल्पिक) - अपने खेत के स्थान के आधार पर सटीक मौसम के लिए
5. **सेटिंग्स सहेजें** - "सहेजें" बटन पर क्लिक करें

### 2. मिट्टी की जाँच कैसे करें

1. **मिट्टी उर्वरता** पर जाएं
2. अपने सॉइल हेल्थ कार्ड से मान दर्ज करें:
   - नाइट्रोजन (N): 0-200 mg/kg
   - फास्फोरस (P): 0-200 mg/kg
   - पोटैशियम (K): 0-300 mg/kg
3. **"जाँच करें"** पर क्लिक करें

### 3. फसल सिफारिश प्राप्त करना

1. **फसल सिफारिश** पर जाएं
2. सभी आवश्यक जानकारी भरें
3. **"सिफारिश करें"** पर क्लिक करें
4. अनुशंसित फसल और उगाने के टिप्स देखें

### 4. चैटबॉट का उपयोग

**खोलने के लिए**: 💬 चैट आइकन पर क्लिक करें

**सवाल पूछें**:
- "मुझे कौन सी फसल उगानी चाहिए?"
- "मेरी मिट्टी कैसी है?"
- "मौसम का जोखिम क्या है?"

2. The app caches essential data
3. Use without internet for predictions
4. Weather data updates when online
